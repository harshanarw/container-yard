How it works

  • Codes live in config/modules.php — the single source of truth.
  • Roles are granted codes with wildcard patterns: yard.* grants every yard code, billing.*.view grants view on all billing, * grants everything.
  • Assign in Settings → Access Control, or run the seeders:
php artisan permissions:sync                        # register codes from config
php artisan db:seed --class=RolePermissionSeeder    # (re)assign role patterns
php artisan config:clear                            # modules.php is cached config

The System Administrator is a super-user that bypasses RBAC entirely. Modules marked system are reserved for it and can't be granted to ordinary roles.

Roles at a glance

Administrator

Full access to everything.

Billing Manager

All billing; view + toggle tariffs; view customers, containers, reports.

Billing Clerk

Billing view / create / PDF; view customers & containers.

Yard Supervisor

All yard ops, surveys, estimates, work orders, approvals, containers; view customers & reports.

Gate Officer

Gate-in/out, reefer, hires, cargo transfers, guard post; view containers & customers.

Inspector

Surveys & estimates; view containers & customers.

Security Officer

Guard post; view containers.

System Administrator

Super-user — bypasses all permission checks. Not assignable; reserved for system owners.

Role access on each module: Role full access Role (actions) partial System Admin only
